# Player

Нативный музыкальный плеер для iPhone (SwiftUI, iOS 18+). Играет ваши файлы MP3, M4A/AAC, ALAC, WAV, AIFF и FLAC, работает в фоне и на экране блокировки, управляется с AirPods и Bluetooth-гарнитур. Без рекламы, аналитики и сетевых запросов: сеть используется только для загрузки файла по ссылке, которую вы сами ввели.

Ниже — всё, что нужно сделать **на компьютере с Windows и на iPhone**. Mac не нужен: приложение собирается в облаке GitHub Actions.

> **Уже установлена версия 1.0?** Сразу переходите к разделу [«Обновление без потери музыки»](#обновление-без-потери-музыки).

---

## 1. Скачать .ipa с GitHub

1. Откройте репозиторий на github.com и войдите в свой аккаунт GitHub (без входа скачать сборку нельзя).
2. Вкладка **Actions** → слева **Build**.
3. Откройте последний запуск с зелёной галочкой ✅ (для нужной ветки).
4. Внизу страницы, в разделе **Artifacts**, нажмите **Player-ipa** — скачается `Player-ipa.zip`.
5. Распакуйте архив (правой кнопкой → «Извлечь всё…»). Внутри — **`Player.ipa`**.

> Сборки хранятся 30 дней. Если артефакт пропал, на странице **Actions → Build** нажмите **Run workflow** → **Run workflow** — через несколько минут появится свежая сборка.

## 2. Подготовить Windows

1. Установите **iTunes** и **iCloud** с сайта Apple — **не из Microsoft Store** (версии из Store с Sideloadly не работают):
   - iTunes для Windows (64-bit): https://www.apple.com/itunes/download/win64
   - iCloud для Windows: ссылку на версию не из Microsoft Store даёт сам Sideloadly на своей странице загрузки (https://sideloadly.io).
   Если версии из Microsoft Store уже стоят — сначала удалите их.
2. Установите **Sideloadly** с официального сайта https://sideloadly.io.
3. Перезагрузите компьютер.

## 3. Установить приложение через Sideloadly

1. Подключите iPhone к компьютеру кабелем. На iPhone нажмите **«Доверять этому компьютеру»** и введите код-пароль.
2. Запустите Sideloadly. В поле устройства должен появиться ваш iPhone.
3. Перетащите `Player.ipa` в окно Sideloadly (или нажмите на значок IPA и выберите файл).
4. В поле **Apple account** введите свой Apple ID (подойдёт бесплатный).
5. Нажмите **Start**, введите пароль Apple ID и, если попросят, код двухфакторной проверки, пришедший на iPhone.
6. Дождитесь надписи **Done**.

> В расширенных настройках Sideloadly (**Advanced options**) ничего менять не нужно. Особенно **не меняйте Bundle ID** — иначе при следующей установке iPhone посчитает приложение новым, и музыка внутри старого пропадёт вместе с ним.

## 4. Включить «Режим разработчика» на iPhone

Нужен один раз (iOS 16 и новее):

1. **Настройки → Конфиденциальность и безопасность → Режим разработчика** (пункт появляется после первой установки через Sideloadly).
2. Включите переключатель → **Перезагрузить**.
3. После перезагрузки подтвердите включение режима и введите код-пароль.

## 5. Доверять профилю разработчика

1. **Настройки → Основные → VPN и управление устройством**.
2. В разделе «Приложение разработчика» выберите свой Apple ID → **Доверять «…»** → **Доверять**.
3. Приложение **«Player»** теперь открывается с рабочего стола.

## 6. Продление подписи каждые 7 дней

С бесплатным Apple ID подпись действует **7 дней**. После этого приложение перестаёт открываться, **но музыка и плейлисты внутри сохраняются**.

Чтобы продлить:

1. Подключите iPhone к компьютеру (или к той же Wi-Fi-сети, если в Sideloadly включено продление по Wi-Fi).
2. Снова установите тот же `Player.ipa` **с тем же Apple ID** — поверх установленного. **Не удаляйте приложение с iPhone** перед этим: удаление стирает всю музыку внутри.
3. В Sideloadly есть автоматическое продление (опция автообновления в расширенных настройках при установке): компьютер должен быть включён, Sideloadly — запущен, а iPhone — в одной Wi-Fi-сети с компьютером. Если опции в вашей версии нет — просто повторяйте шаг 2 раз в неделю.

Ограничения бесплатного Apple ID: одновременно не больше **3** установленных так приложений и не больше **10** новых приложений (App ID) за 7 дней.

### Вариант: продлевать прямо с телефона (SideStore)

**SideStore** — приложение для iPhone, которое продлевает подпись без компьютера (компьютер с Windows нужен один раз — для первоначальной настройки).

1. Установите SideStore по официальной инструкции для Windows: https://docs.sidestore.io (там же описано, как получить pairing-файл и какое VPN-приложение из App Store нужно для продления на телефоне).
2. Скачайте `Player.ipa` на iPhone (например, через iCloud Drive), откройте SideStore → **My Apps** → **+** → выберите `Player.ipa`.
3. Раз в несколько дней открывайте SideStore и нажимайте **Refresh All** (или включите фоновое продление в его настройках).

> Приложение, установленное через SideStore, и приложение, установленное через Sideloadly, — **разные** приложения для iPhone со своей музыкой. Выберите один способ и продлевайте только им.

## Обновление без потери музыки

Музыка, плейлисты, настройки и место, где вы остановились, хранятся **внутри приложения на iPhone**. Новая версия подхватывает их сама — если поставить её **поверх** старой. Порядок:

1. Скачайте свежий `Player.ipa` (раздел 1).
2. Подключите iPhone к компьютеру и откройте Sideloadly.
3. **Не удаляйте приложение с iPhone.** Удаление стирает всю музыку внутри — восстановить её будет нельзя.
4. В поле **Apple account** — **тот же Apple ID**, что и при первой установке.
5. **Advanced Options** в Sideloadly **не трогайте** (особенно Bundle ID). Если что-то там меняли раньше — верните как было при первой установке.
6. Нажмите **Start** и дождитесь **Done**. Откройте приложение — библиотека на месте.

Что изменится после обновления до 1.1:

- Подпись под иконкой и папка в «Файлах» теперь называются **Player** (раньше — «Плеер»). Это та же папка того же приложения, файлы в ней остались.
- Если файл библиотеки когда-нибудь окажется повреждён, приложение не сотрёт его: сделает рядом резервную копию, восстановит из него всё, что читается (песни, плейлисты), и заново найдёт музыку в папке. Музыкальные файлы при этом не трогаются.
- Файлы, которые не удалось добавить через «Поделиться / Открыть в», больше не удаляются — они лежат в «Файлы» → «На iPhone» → «Player» → «Не импортировано».

## Как сменить иконку

1. В приложении: вкладка «Песни» → значок ⚙︎ слева вверху → **«Иконка приложения»**.
2. Нажмите на понравившийся вариант: Аврора (основная), Закат, Океан, Мята, Графит, Бумага или Неон.
3. iOS покажет уведомление «Вы изменили значок…» — это **нормально**, его показывает сама система. Нажмите «OK».

Музыка при смене иконки не останавливается. У каждой иконки есть тёмный и «тонированный» вариант — они включаются сами, если в iOS выбран такой стиль значков (долгое нажатие на рабочий стол → «Править» → «Настроить»). После переустановки приложения поверх iOS обычно сохраняет выбранную иконку; если она сбросилась на основную — просто выберите её снова.

Там же, в **Настройках → Оформление**, можно выбрать **акцентный цвет** интерфейса (Фуксия, Лазурь, Мята, Янтарь, Фиалка или Неон) и тему.

## 7. Как добавлять музыку

- **Из «Файлов»:** в приложении нажмите **«+» → «Из Файлов»** и выберите одну или несколько песен (с iPhone, из iCloud Drive и т. п.). Файлы копируются внутрь приложения.
- **Из другого приложения:** «Поделиться» → **«Player»** (или «Открыть в…» → «Player»).
- **Через приложение «Файлы»:** «Файлы» → **«На iPhone» → «Player»** — положите туда песни (можно папками). При возвращении в «Player» они появятся сами.
- **С компьютера Windows через iTunes:** подключите iPhone, откройте iTunes → значок iPhone → **«Общие файлы»** → **«Player»** → перетащите песни в правую часть окна.
- **С компьютера через iCloud Drive:** положите файлы в iCloud Drive на компьютере, затем на iPhone **«+» → «Из Файлов»** → iCloud Drive.
- **По ссылке:** **«+» → «По ссылке»** → вставьте прямую ссылку `https://…` на файл. Ссылки `http://` не поддерживаются (незащищённое соединение) — используйте тот же адрес с `https://`.

Поддерживаются MP3, M4A/AAC, ALAC, WAV, AIFF и FLAC. Ogg Vorbis, Opus, WMA и APE iOS не воспроизводит — приложение сообщит об этом.

## 8. Возможности

- Вкладки «Песни», «Альбомы», «Исполнители», «Плейлисты»; поиск, сортировка, удаление.
- Очередь: «Играть следующим», «В конец очереди», перестановка, shuffle, повтор (выкл / вся очередь / один трек).
- Перемотка кнопками на 5 / 10 / 15 / 30 секунд (настраивается).
- Фоновое воспроизведение, экран блокировки, Пункт управления, AirPods и Bluetooth-кнопки, выбор устройства вывода (AirPlay).
- Пауза при отключении наушников / Bluetooth и при звонке; продолжение после звонка, если iOS разрешила.
- Таймер сна (в т. ч. «в конце трека»), запоминание трека, позиции и очереди.
- Смена иконки приложения (7 вариантов) и акцентного цвета интерфейса.
- Тёмная и светлая тема, русский и английский языки, VoiceOver, крупный шрифт, «Уменьшение движения», «Понижение прозрачности».

## 9. Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Sideloadly не видит iPhone | Переустановите iTunes с сайта Apple (не из Store), подключите кабель напрямую, нажмите «Доверять» на iPhone. |
| «Ненадёжный разработчик» при запуске | Пункт 5: доверьте профилю. |
| Приложение не открывается через неделю | Истекла подпись — пункт 6, установите поверх. |
| Песня серая с ⚠ | Файл удалён или повреждён. «Настройки» → «Убрать отсутствующие файлы». |
