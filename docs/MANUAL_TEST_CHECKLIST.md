# Чек-лист ручной проверки на iPhone

Отмечайте ✅ / ❌. Если что-то не так — запишите, что делали и что увидели.

## Подготовка
- [ ] В библиотеке есть хотя бы 3 песни, у одной есть обложка, у одной — нет.
- [ ] Есть наушники с проводом (или переходник) и/или AirPods / Bluetooth-гарнитура.

## Фоновое воспроизведение
- [ ] Включить песню → свайп домой (выход на рабочий стол). Музыка **продолжает** играть.
- [ ] Заблокировать iPhone боковой кнопкой. Музыка **продолжает** играть.
- [ ] Переключиться в другое приложение (Safari, Камера-фото без видео). Музыка играет.
- [ ] Оставить играть до конца трека в фоне — начинается следующий трек.
- [ ] Включить таймер сна на 5 минут, заблокировать телефон — через 5 минут звук плавно затихает и останавливается.

## Экран блокировки
- [ ] На экране блокировки видны название, исполнитель, альбом и обложка.
- [ ] Трек без обложки — показывается без картинки, без ошибок.
- [ ] Кнопка ⏯ ставит на паузу и снимает с паузы.
- [ ] Кнопки ⏮ / ⏭ переключают треки (настройка «Экран блокировки: Треки»).
- [ ] «⏮» после 3 секунд трека перематывает его в начало, в первые 3 секунды — к предыдущему.
- [ ] Ползунок на экране блокировки перематывает трек.
- [ ] В «Настройках → Экран блокировки» выбрать «Перемотка ±N с»: на экране блокировки вместо ⏮ / ⏭ кнопки перемотки на выбранный интервал.
- [ ] Время на экране блокировки совпадает со временем в приложении после паузы и перемотки.

## Пункт управления
- [ ] В Пункте управления виден плеер с тем же треком, ⏯ / ⏮ / ⏭ / ползунок работают.
- [ ] Кнопка AirPlay в Пункте управления показывает доступные устройства.

## AirPods / Bluetooth
- [ ] Подключить AirPods / гарнитуру. Звук идёт в них.
- [ ] Нажатие (двойное касание / кнопка на гарнитуре) ставит на паузу и продолжает.
- [ ] Двойное / тройное нажатие (если поддерживается) переключает треки.
- [ ] В экране «Сейчас играет» кнопка выбора устройства (треугольник с кругами) показывает AirPods / колонку; переключение работает.
- [ ] Ползунок громкости в приложении двигается вместе с аппаратными кнопками громкости.
- [ ] **Отключить Bluetooth посреди трека** (или убрать AirPods в футляр / выключить колонку) — воспроизведение **ставится на паузу**, музыка НЕ начинает играть из динамика.

## Проводные наушники
- [ ] Выдернуть наушники во время воспроизведения — **пауза**.
- [ ] Вставить обратно и нажать ⏯ — воспроизведение продолжается.

## Звонки и прерывания
- [ ] Во время воспроизведения позвонить на iPhone с другого телефона — музыка становится на паузу.
- [ ] Сбросить / завершить звонок — музыка **сама продолжает** играть (если iOS это разрешила).
- [ ] Вызвать Siri во время воспроизведения → закрыть Siri — воспроизведение продолжается.
- [ ] Сработавший будильник/таймер iOS ставит музыку на паузу.
- [ ] Включить видео в другом приложении — наш плеер останавливается и сам НЕ включается после закрытия видео.

## Библиотека и импорт
- [ ] «+» → «Из Файлов» → выбрать несколько песен → появились в «Песнях».
- [ ] В приложении «Файлы» → «Поделиться» → «Плеер» — песня добавилась.
- [ ] Через «Файлы» → «На iPhone» → «Плеер» положить mp3 → вернуться в приложение — песня появилась.
- [ ] «+» → «По ссылке» → https-ссылка на mp3 → прогресс, затем «Добавлено».
- [ ] Ссылка http:// — понятная ошибка с подсказкой про https://.
- [ ] Ссылка на веб-страницу — понятная ошибка.
- [ ] Импорт .ogg / .opus — понятное сообщение «формат не поддерживается», без вылета.
- [ ] Удалить файл через «Файлы», пока он играет, — приложение не вылетает; после возврата песня помечена «Файл не найден».
- [ ] Поиск, сортировка, удаление песни (с подтверждением) работают.
- [ ] Плейлист: создать, добавить песни, переставить, удалить песню из плейлиста, переименовать, удалить.

## Очередь и режимы
- [ ] Shuffle перемешивает, при выключении порядок возвращается.
- [ ] Repeat: выкл → вся очередь → один трек.
- [ ] «Играть следующим» и «В конец очереди» из долгого нажатия.
- [ ] В «Очереди» перетаскивание меняет порядок, свайп удаляет.

## Восстановление
- [ ] Закрыть приложение из переключателя приложений и открыть снова — тот же трек, позиция и очередь, **звук сам не включается**.

## Внешний вид и доступность
- [ ] Тёмная тема по умолчанию; в настройках переключается на светлую.
- [ ] Мини-плеер над таб-баром; нажатие открывает плеер с плавным переходом; свайп вниз закрывает.
- [ ] Фон экрана «Сейчас играет» меняется под обложку, плавно при смене трека.
- [ ] Обложка уменьшается на паузе и увеличивается при воспроизведении.
- [ ] «Настройки iPhone → Универсальный доступ → Движение → Уменьшение движения» — анимации становятся спокойнее, всё работает.
- [ ] Крупный шрифт (Настройки → Экран и яркость → Размер текста) — текст не обрезается критично.
- [ ] VoiceOver: все кнопки плеера озвучиваются понятно.
- [ ] Очень длинное название песни не ломает вёрстку.
- [ ] Библиотека на 1000+ песен прокручивается плавно.
