случаи (нет места, битый файл, файл удалён во время воспроизведения, звонок,

(0 предупреждений), unit-тесты, Periphery (`--strict`). Поиск запрещённых
конструкций (`!`-развёртывание, `try!`, `as!`, `fatalError`, `precondition`,

### Ограничения, которые нельзя закрыть кодом

- Работа в фоне, экран блокировки, AirPods, звонки и Bluetooth проверяются
  только на реальном iPhone — по `docs/MANUAL_TEST_CHECKLIST.md`.
- `MPVolumeView` не отображается в симуляторе (ограничение iOS).
- Песни из сборников с разными исполнителями группируются в альбомы по паре
  «исполнитель + альбом», поэтому сборник может распасться на несколько альбомов.
