# Аудит кода

Проверка по чек-листу: баги, утечки, гонки, необработанные ошибки, краевые
случаи (нет места, битый файл, файл удалён во время воспроизведения, звонок,
отключение Bluetooth, длинные названия, нет обложки, 0 и 1000+ треков),
мёртвый код, соответствие ТЗ.

Автоматические проверки в CI на каждом коммите: сборка с
`SWIFT_TREAT_WARNINGS_AS_ERRORS = YES` и Strict Concurrency = Complete
(0 предупреждений), unit-тесты, Periphery (`--strict`). Поиск запрещённых
конструкций (`!`-развёртывание, `try!`, `as!`, `fatalError`, `precondition`,
IUO) в `App/` — 0 совпадений.
