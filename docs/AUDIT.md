## Версия 1.1

Два прохода по всему коду (`App/`, `Tests/`, CI), а не только по изменённому.
Чек-лист: сохранность данных при обновлении, баги, утечки (observers, `Task`,
замыкания, targets `MPRemoteCommandCenter`), гонки при Strict Concurrency =
Complete, необработанные ошибки, `!`/`try!`/`as!`/`fatalError` (0 совпадений),
мёртвый код (Periphery `--strict` в CI), соответствие ТЗ v1.1; сценарии: фон и
экран блокировки, Пункт управления, AirPods/Bluetooth и отключение наушников,
звонок, смена иконки и импорт во время воспроизведения, удалённый/битый файл,
0 и 1000+ треков, очень длинные названия.

#### Ограничения, которые нельзя закрыть кодом

- Работа в фоне, экран блокировки, AirPods, звонки и Bluetooth проверяются
  только на реальном iPhone — по `docs/MANUAL_TEST_CHECKLIST.md`.
- `MPVolumeView` не отображается в симуляторе (ограничение iOS).
- Песни из сборников с разными исполнителями группируются в альбомы по паре
  «исполнитель + альбом», поэтому сборник может распасться на несколько альбомов.
